# oddssea for Python

The Python client for the [oddssea](https://oddssea.dev) API: Pinnacle odds, prematch and live, over REST and
WebSocket.

**In development.** Nothing is published on PyPI yet. Until it is, the API works with any HTTP and WebSocket
library: see the [API docs](https://oddssea.dev/docs).
